# Manual de Usuario - GymPOS

## Inicio del sistema
Al ejecutar la aplicacion se abre la ventana principal de GymPOS.

## Pantalla principal
La pantalla muestra:

- menu superior
- tabla de clientes
- formulario para registrar clientes
- botones de agregar, actualizar, eliminar y limpiar

## Agregar cliente

1. Escribir ID del cliente
2. Escribir nombre
3. Escribir telefono
4. Escribir correo
5. Presionar Agregar

## Actualizar cliente

1. Seleccionar un cliente de la tabla
2. Modificar los datos en el formulario
3. Presionar Actualizar

## Eliminar cliente

1. Seleccionar un cliente
2. Presionar Eliminar

## Limpiar formulario

Presionar el boton Limpiar para borrar los campos.

## Menu superior

### Archivo
Permite salir del sistema.

### Ayuda
Muestra informacion basica del sistema.

## Validaciones
El sistema valida que los campos no esten vacios.

## Recomendaciones
Usar IDs unicos para cada cliente.
