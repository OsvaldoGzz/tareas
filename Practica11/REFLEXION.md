# Reflexion

## 1. Hilo de la UI

El hilo de la UI es el que maneja la interfaz grafica.

No se deben hacer tareas pesadas ahi porque la interfaz se puede congelar.


## 2. EventHandler

Un EventHandler detecta acciones del usuario.

Sirve para conectar lo que hace el usuario con la logica del programa.


## 3. Stage, Scene y Node

Stage es la ventana principal.

Scene es el contenido dentro de la ventana.

Node son los elementos como botones o tablas.
