# Manual de Usuario

## Inicio

Al ejecutar el programa se abre una ventana con:

- tabla de productos
- formulario
- menu superior


## Agregar producto

1. Llenar los campos del formulario
2. Presionar "Agregar"


## Actualizar producto

1. Seleccionar un producto en la tabla
2. Modificar datos
3. Presionar "Actualizar"


## Eliminar producto

1. Seleccionar un producto
2. Presionar "Eliminar"


## Buscar productos

Escribir en el campo de busqueda.

La tabla se actualiza automaticamente.


## Validaciones

- No se permiten campos vacios
- Precio debe ser mayor a 0
- Stock no puede ser negativo


## Menu

- Archivo → salir
- Ayuda → informacion del sistema
